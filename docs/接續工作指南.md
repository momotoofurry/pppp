## 0. 同一台電腦、換帳號（最常見）

- **換 Claude 帳號、Windows 使用者不變**：什麼都不用搬。
  - Claude Code 的設定和工作記憶在 `C:\Users\<你>\.claude\` 底下，跟著 Windows 使用者，不跟 Claude 帳號；新帳號開同一個專案資料夾就會載入。
  - WSL、Docker、`D:\selftest_data`、repo 都不變。
  - 第一次可以請它「先讀 `claude/memory/MEMORY.md` 和這份指南的第 3 節」確認進度。
- **換 Windows 使用者**：
  - WSL 是每個 Windows 使用者各自一份，要照第 2 節重裝 WSL、repo、Docker、ROS 2；
  - `D:\selftest_data` 通常其他使用者也讀得到，不用搬；
  - Claude 的記憶照第 1 節從 `claude/memory/` 複製。
- 換電腦才需要第 5 節的 Google Drive。

## 1. 新的 Claude（新帳號或新電腦）怎麼接上

1. 在 repo 的根目錄開 Claude Code，它會自動讀 `CLAUDE.md`。
2. 第一句話請它：「先讀 `claude/memory/MEMORY.md` 和它列出的每個檔案，再讀 `docs/接續工作指南.md`」。記憶檔裡有你的偏好和規則（繁體中文、判準先寫、凍結的東西不改、KB = 1024、論文寫作規則等）、做過的決定和進行中的工作。
3. 想讓它自動記得：把 `claude/memory/*.md` 複製到 `~/.claude/projects/<專案代號>/memory/`。專案代號就是工作目錄的路徑，把 `:`、`\`、`/` 換成 `-`，例如 `C--Users-<你>-...`；先開一次 Claude Code，資料夾就會出現。
4. 記憶檔是 2026-11-28 的狀態；裡面提到的檔名、commit 用之前先確認還存在。

## 2. 新電腦的環境

**Windows 11**
- WSL：`wsl --install -d Ubuntu-22.04`。`/etc/wsl.conf` 加 `[boot] systemd=true`。
  - **然後在 WSL 終端機執行 `sudo systemctl disable --now systemd-timesyncd`**，再 `wsl --shutdown`。不關的話 kernel 的 tick 會被改掉，單調時鐘會慢 5 %（report 35.109）。
- Docker Desktop，開啟 Ubuntu-22.04 的 WSL 整合。
  - 每次 `wsl --shutdown` 後，WSL 整合會斷，要在 Docker Desktop 按「Restart the WSL integration」或重開 Docker Desktop。
- Python 3.10（Windows）：實驗室工具的 Python 版、`tools/local-monitor`。
- STM32CubeCLT，或 VS Code 的 STM32 擴充套件：編韌體、燒錄（`firmware/README.md`）。
- Ollama＋`ollama pull qwen3:4b-instruct-2507-q4_K_M`：只有本地 AI 監看要用。
- 實驗室電腦：Delsys 的 Trigno Control Utility；`TrignoBridge.exe`、`TaskScreen.exe`、`ExperimentPanel.exe` 用 Windows 內建的 csc 從 `src/pc/*.cs` 編，指令在 `lab_kit/README.md`。

**WSL（Ubuntu 22.04）**
```bash
git clone git@github.com:momotoofurry/pppp.git ~/model-leaf      # 放在 Linux 的檔案系統，不要放 /mnt/c
cd ~/model-leaf && docker/run.sh build                            # 分析用的映像 rf-emg
sudo apt install ros-humble-desktop ros-humble-kortex-bringup ros-humble-kortex-driver ros-humble-kortex-description \
  ros-humble-gazebo-ros ros-humble-gazebo-ros2-control ros-humble-joint-trajectory-controller
```
- 以上是作者電腦上實際裝的 ROS 2 套件（還有 MoveIt，目前沒用到）。ROS 2 Humble 的 apt 來源設定照 ROS 官方的安裝說明。
- `src/pc/sim/gen3_sim.sh` 第一次跑會自己建 robotiq 的 overlay（`~/.cache/kinova_sim_overlay`）。
- GitHub：在 WSL 產生 SSH 金鑰，加到 GitHub 帳號。
