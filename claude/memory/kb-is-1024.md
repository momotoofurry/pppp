Write all memory and code sizes (RAM, Flash, buffers) with 1 KB = 1024 bytes, in report.md, PROPOSAL.md, the proposal deck and thesis prose. Give the exact byte count too when it matters.

**Why:** the user chose 1024 on 2026-11-13 after the proposal (÷1000) and the deck (÷1024) showed the same firmware as 24.9 KB and 24.4 KB.

**How to apply:** compute KB as bytes / 1024. When copying numbers from linker or `size` output, convert this way, and check older text for ÷1000 leftovers. Related: [[thesis-writing-rules]].
